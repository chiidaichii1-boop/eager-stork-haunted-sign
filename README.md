## What this entry does

`main.py` writes a single funny sign for the door of a haunted server
room into `entry.txt` (in `$MAKEFUN_OUTPUT_DIR`, or `/output` by default):

> WARNING: The ghost in this server room has root access, and it reboots the servers at 3 a.m. just for fun.

The line is under the 120-character limit, uses only the Python standard
library, and is fully deterministic — every run writes the exact same line.
